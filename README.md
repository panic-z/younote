# YouTube 视频笔记

在桌面 Chrome 的 YouTube 点播页记录带时间点的私人笔记。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `youtube-video-notes` 文件夹。
4. 打开或刷新一个 YouTube 点播视频。播放器下方会显示「视频笔记」面板。

扩展使用 Manifest V3 和原生 JavaScript，直接加载项目目录即可运行。

## 使用

- 直接在播放器下方的输入框写笔记。开始输入时，视频会暂停并绑定当前播放时间。写完点「保存」。
- 点击时间线上的圆点或列表里的时间戳，跳到对应位置并暂停。
- 点击「已保存笔记」展开或收起列表，时间线和输入框仍可使用。
- 在面板右上角选择「下方」「左侧」「右侧」或「浮窗」。扩展会记住所选布局。拖动浮窗标题可移动窗口，拖动底部任一角可调整整个窗口的宽度和高度。也可以聚焦标题或底部手柄后按方向键操作。
- 点击「编辑」可修改正文。要换个位置，先拖动 YouTube 的进度条，再点「绑定当前时间」。
- 在同一标签页内通过 YouTube 切换视频后，返回原视频可继续编辑未保存的笔记。
- 点击「删除」移除笔记。重新打开同一个视频时，扩展会按视频 ID 恢复已保存的笔记。

旧版的画面帧笔记会沿用原标记的位置，作为时间点显示。

## 导出与导入

点面板右上角的「导出」，下载一个 Markdown（`.md`）文件。笔记按视频分组，包含视频链接、每条笔记的时间戳和正文。可以用任意文本编辑器打开，也可以在 Markdown 阅读器里查看。

点「导入」并选择导出的 Markdown 文件，即可把笔记恢复到对应的视频。手动编辑备份时，请保留视频标题和 `<!-- ... -->` 注释，正文每行以 `>` 开头。注释保留笔记标识和原始时间精度。重复导入会跳过已有笔记，保留本地内容。旧版 JSON 备份也可以导入。

数据存放在当前 Chrome 配置的扩展本地存储中。清除扩展数据或卸载扩展会移除笔记。首版支持 `www.youtube.com/watch` 普通点播页。

## 测试

在项目目录运行 `node --test`，可验证时间点绑定、跳转中断、切页保存和导入兼容性。
